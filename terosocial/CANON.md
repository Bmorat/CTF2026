# TeroSocial — Canon de la plataforma

Documento maestro. **Toda pieza de contenido (posts, grupos, avisos, eventos)
debe respetar los alias y datos de acá.** Si algo no está en este documento, no
existe en TeroSocial.

Regla de oro: **nada de personas, empresas, organismos o medios reales.** Todo
inventado. Lugares geográficos reales sí (barrios, ciudades, rutas, playas).

### Las tres épocas del sanitizador de metadatos

Regla del mundo que explica por qué unas fotos conservan datos y otras no:

| Época | Qué pasa con las imágenes subidas |
|-------|-----------------------------------|
| 2018 – 2020 | La plataforma era nueva y no limpiaba nada → **conservan metadatos** |
| 2020 – marzo 2026 | Sanitizador funcionando → salen limpias |
| Desde el 14/3/2026 | Sanitizador caído (avisado en el login) → **conservan metadatos otra vez** |

Por eso la lámina de 2018 tiene datos adentro sin contradecir el aviso, y por eso todo
el contenido de aves de 2026 sirve de ruido legítimo. **Ninguna foto con metadatos puede
estar fechada entre 2020 y marzo de 2026.**

## 3. Esquema de datos

Todos los archivos son JS plano (`window.X = ...`) para que funcione sin servidor.

### `datos_usuarios.js` → `window.USUARIOS = [ ... ]`

```js
{
  alias: "elrusodelquiosco",       // único, minúsculas, [a-z0-9_.]
  nombre: "Sergio Ibarra",
  bio: "…",                        // 1-2 líneas, lo que se ve
  bio_extendida: "…",              // versión larga (se expande con el botón)
  estado: "…",                     // frase corta del momento
  ubicacion: "Goes, Montevideo",
  se_unio: "2021-03-14",           // AAAA-MM-DD
  avatar: "iniciales",             // o "media/archivo.svg"
  verificado: false,
  seguidores: 312,
  siguiendo: 287,
  oculto: false,                   // true = no aparece en buscador ni sugerencias
  grupos: ["vecinos-cerro", "comprovendo"]
}
```

### `datos_posts.js` → `window.POSTS = [ ... ]`  (feed general)

```js
{
  id: 1042,                        // único en TODA la plataforma
  autor: "elrusodelquiosco",       // debe existir en USUARIOS
  fecha: "2026-07-14T19:20:00-03:00",
  texto: "…",
  imagen: null,                    // o "media/archivo.svg"
  grupo: null,                     // null = feed general; o slug de grupo
  likes: 41,
  comentarios: [
    { autor: "laura.rambla", texto: "…", fecha: "2026-07-14T19:40:00-03:00",
      respuestas: [                // opcional, un nivel de anidación

      ]
    }
  ],
  encuesta: null                   // o { pregunta, opciones:[{texto,votos}], cierra }
}
```

## 4. Reglas de escritura del contenido

1. **Español rioplatense.** Voseo (*vos tenés*, *mirá*, *dale*), *ta*, *bo*, *ni ahí*,
   *de más*, *salado*, *bo qué lindo*. Nada de *tú* ni de *coger*.
2. **Nadie escribe perfecto.** Faltas de ortografía, mayúsculas de más, tildes que
   faltan, audios mencionados que nadie puede oír, "ya te paso por privado".
3. **Las conversaciones se desvían.** Un post de una bicicleta termina en política.
   Alguien pregunta el precio en un post que no vende nada.
4. **Rangos de fechas:** de enero 2019 a agosto 2026, con densidad creciente hacia
   2026. El "hoy" de la plataforma es **5 de agosto de 2026**.
5. **Coherencia de horarios:** el tambero publica a las 5 AM, el remisero a las 3 AM,
   la enfermera en turnos rotativos, la maestra de tarde.
6. **Nada de personas reales.** Ni políticos, ni futbolistas, ni periodistas, ni
   empresas existentes. Clubes de fútbol reales solo como pasión ("hincha de…"),
   nunca poniéndoles declaraciones ni hechos falsos.
7. **La posta discute consigo misma.** Por cada teoría hay alguien que la compra,
   alguien que la exagera y alguien (`escepticouy`, `hacker_del_prado`, `astro.mvd`,
   `agronomo_paysandu`, `profe_hernandez_hist`) que la desarma con datos. Esa
   tensión es el valor pedagógico del grupo.
8. **Ganchos naturales.** Sin sembrar flags todavía, el contenido debe ofrecer
   material aprovechable después: fotos con descripción de lugar, horarios, rutinas,
   menciones cruzadas entre cuentas, coincidencias, datos de contacto, alias
   parecidos entre sí.
